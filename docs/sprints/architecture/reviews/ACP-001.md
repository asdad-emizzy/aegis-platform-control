# Architecture Checkpoint 001 — Investigation, Finding, Recommendation & Investigation Provider Boundaries

**Status:** PASS WITH CONDITIONS

**Date:** 2026-09-04

**Mode:** Architecture Checkpoint — documentation only

## Objective

Resolve ownership and provider-boundary ambiguity before implementation of Findings, Recommendations, or investigation-provider integration.

## Inspection Result

The uploaded repository contains a strong product framework in `FRAMEWORKS.md` and investigation-oriented implementation in `src/lib/investigations.ts`, but the expected `.ai/` directory is absent. Several architecture artifacts are empty placeholders, including `docs/architecture/ARCHITECTURE.md`, `COMPONENT_MODEL.md`, `CONTEXT_MAP.md`, and `docs/architecture/DEPLOYMENT_ARCHITECTURE.md`. ADR-0002, ADR-0003, ADR-0004, and ASR-002 are also empty.

The product framework explicitly distinguishes Evidence, Finding, Hypothesis, Recommendation, and Root Cause. It also explicitly describes HolmesGPT as an investigation provider, Hindsight as a memory provider, and Agent Orchestrator as a lifecycle coordinator.

## Findings

### ACP-001-F01 — Finding ownership conflict

**Finding:** ADR-0005 incorrectly states that Finding is owned by Recommendations, while the product framework defines Finding as an interpretation supported by evidence.

**Impact:** Future implementation could collapse investigation conclusions and operational decisions.

**Decision:** Finding belongs to Investigation. Recommendation belongs to Recommendations.

### ACP-001-F02 — Root Cause boundary ambiguity

**Finding:** Root Cause is described separately from Finding but no canonical ownership exists.

**Decision:** Root Cause is a classification of a sufficiently supported Finding, not a separate domain/provider.

### ACP-001-F03 — Investigation provider boundary is conceptual only

**Finding:** The repository describes `InvestigationProvider` and HolmesGPT but contains no provider contract implementation in the uploaded source tree.

**Decision:** `InvestigationProvider` is an Investigation capability port; HolmesGPT is an adapter/provider implementation. Concrete contract implementation is deferred.

### ACP-001-F04 — Memory and orchestration boundaries must remain separate

**Decision:** Hindsight is a `MemoryProvider`; Agent Orchestrator is a coordinating control component. Neither owns Investigation artifacts.

### ACP-001-F05 — Architecture governance artifacts are incomplete

**Finding:** `.ai/` is absent from the uploaded repository, several architecture model documents are empty, and ADR-0002/3/4 are empty placeholders.

**Impact:** The architecture cannot currently be considered fully governed from the repository alone.

**Recommendation:** Restore/complete the canonical AI knowledge base and empty governance artifacts in a dedicated governance slice.

## Canonical Architecture

```text
Incident
   ↓
Investigation
   ↓
Evidence / Knowledge Context
   ↓
Finding / Hypothesis
   ↓
Recommendation
   ↓
Controlled Action
   ↓
Verification
```

Provider boundary:

```text
Investigation
   ↓
InvestigationProvider
   ↓
Provider Adapter
   ↓
HolmesGPT / future providers
```

Supporting providers:

```text
MemoryProvider    → Hindsight
ReasoningProvider → LLM / LCM
TelemetryProvider → CloudWatch / Prometheus / others
```
