The Architecture Decision Records (ADRs) are especially important. Every major decision should be captured there, for example:

ADR-0001: Grafana is the presentation layer.
ADR-0002: Platform API is the operations intelligence layer, not a telemetry database.
ADR-0003: Grafana Alloy is the standard telemetry collector.
ADR-0004: Telemetry backends must be Prometheus-compatible.
ADR-0005: Every external integration uses a provider interface.

These ADRs become your project's "constitution."
